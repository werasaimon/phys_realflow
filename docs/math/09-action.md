# 9. Действие

[← Тензоры](08-tensors.md) · [Статистика и сигмы →](10-statistics.md)

Эта глава — мостик к главе SDK [11 «Действие: откуда берутся уравнения»](../11-action.md). Там у каждой физики движка есть свой «паспорт»: действие, уравнения, дискретизация, код, графики, границы. Здесь только главная идея.

## Идея

Мяч, брошенный другу, летит по параболе. Почему именно по ней? Можно рассуждать силами, шаг за шагом, как в [главе 4](04-time-step.md). А можно спросить иначе: из всех путей от руки до руки друга за одну секунду природа выбирает особый. Для каждого воображаемого пути можно посчитать одно число, **действие**. Настоящий путь — тот, на котором действие не меняется при малом шевелении пути.

Это похоже на луч света, который идёт из воздуха в воду по такому пути, чтобы добраться быстрее всего. Спасатель на пляже тоже бежит по песку дольше, а плывёт меньше. Природа везде «экономна», и из этой экономии выводятся все уравнения движения.

## Картинка из движка

![Свободное вращение: дрейф инвариантов Нётер](../images/action/free-rotation-drift.svg)

Главный подарок действия — **теорема Нётер**: каждой симметрии соответствует величина, которая сохраняется. Время течёт одинаково сегодня и завтра, поэтому сохраняется энергия. Пространство одинаково во всех направлениях, поэтому сохраняется момент импульса. На графике движок вращает брусок 20 секунд и следит, насколько уплыли энергия и момент импульса. Идеал — ноль. Дрейф в тысячные доли — это открытый изъян, о котором говорили главы [4](04-time-step.md) и [6](06-quaternions.md).

## Формула

$$
S = \int_{t_0}^{t_1} L(q, \dot q, t)\,dt, \qquad L = T - V, \qquad \delta S = 0
\quad\Longrightarrow\quad
\frac{d}{dt}\frac{\partial L}{\partial \dot q} - \frac{\partial L}{\partial q} = 0 .
$$

Для мяча $L = \tfrac12 m\dot y^2 - m g y$, и уравнение Эйлера–Лагранжа даёт $m\ddot y = -m g$. Это закон Ньютона, выведенный не из сил, а из одного числа.

Диссипативные силы добавляем к консервативной модели через функцию Рэлея $R$:
$Q_d=-\partial R/\partial\dot q$. Без внешней работы их мощность
$dE/dt=Q_d\cdot\dot q$. Для однородной функции степени $k$ это $-kR$:
вязкое сопротивление $R=c|\dot q|^2/2$ даёт **$-2R$**, а сухое трение
$R=\mu N|v_t|$ при скольжении и заданной нормальной реакции $N$ — **$-R$**. В покое реакция трения может быть
ненулевой, но её мощность при $v_t=0$ равна нулю.
Численные примеры проверяет [C++-инструмент](../../tools/BookContactChecks.cpp).

Позиционная коррекция контактов имеет отдельную численную погрешность:
изменение высоты меняет потенциальную энергию даже без прямого изменения
скорости. Поэтому баланс непрерывной модели нельзя автоматически приписывать
всему шагу SDK; [новый разбор цепи](../book/04-energy-sleep-and-chain.md)
показывает это по измерениям.

## Физика

Действие — общий язык всей физики движка: твёрдые тела, ткань, жидкость, газ, магнитное поле и свет у чёрной дыры выводятся из своих действий. Для чёрной дыры это действие Эйнштейна–Гильберта, из которого получаются уравнения Эйнштейна ([глава 8](08-tensors.md)).

## Проверь сам

Положите на стол линейку наклонно, как горку, и пустите по ней шарик. Засеките время. Потом согните картонку дугой, чтобы она была круче вначале, и пустите шарик по ней между теми же точками. По дуге шарик часто приходит быстрее, хотя путь длиннее. Задачу о самом быстром пути, брахистохроне, Иоганн Бернулли решил в 1696 году, и с неё началось вариационное исчисление.
