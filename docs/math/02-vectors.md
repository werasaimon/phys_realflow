# 2. Векторы

[← Числа и точность](01-numbers.md) · [Производная и интеграл →](03-derivative-integral.md)

## Идея

Вектор — это стрелка: у неё есть длина и направление. Скорость ветра, сила толчка, направление взгляда. В компьютере стрелка хранится тремя числами: насколько она уходит вдоль осей $x$, $y$ и $z$.

Со стрелками можно делать два умножения, и оба нужны физике каждую долю секунды:

- **Скалярное произведение** $\mathbf a\cdot\mathbf b$ отвечает на вопрос «насколько стрелки смотрят в одну сторону». Ответ — число. Если толкать тележку вдоль её хода, работа большая; если поперёк, работы нет.
- **Векторное произведение** $\mathbf a\times\mathbf b$ даёт новую стрелку, перпендикулярную обеим. Оно отвечает на вопрос «как это закручивает». Гаечный ключ: чем длиннее ручка и чем сильнее толкнуть поперёк неё, тем сильнее крутит.

## Картинка из движка

![Заряд в магнитном поле идёт по кругу](../img/math/lorentz.svg)

Сила Лоренца $\mathbf F = q\,\mathbf v\times\mathbf B$ всегда перпендикулярна скорости. Она не разгоняет заряд и не тормозит, только поворачивает. Поэтому заряд идёт по кругу. Синяя линия — 200 шагов расчёта, пунктир — точный круг радиуса $m v / (q B) = 1$ м. Они лежат друг на друге.

## Формула

$$
\mathbf a\cdot\mathbf b = a_x b_x + a_y b_y + a_z b_z = |\mathbf a|\,|\mathbf b|\cos\varphi,
$$

$$
\mathbf a\times\mathbf b = \big(a_y b_z - a_z b_y,\; a_z b_x - a_x b_z,\; a_x b_y - a_y b_x\big), \qquad |\mathbf a\times\mathbf b| = |\mathbf a|\,|\mathbf b|\sin\varphi .
$$

Моменты и сила Лоренца:

$$
\boldsymbol\tau = \mathbf r\times\mathbf F, \qquad \Delta\boldsymbol\omega = \mathbf I^{-1}(\mathbf r\times\mathbf J), \qquad \mathbf F = q\,\mathbf v\times\mathbf B .
$$

## Код

Оба произведения — одна строка каждое:

[src/math/Vector3.h:32](../../src/math/Vector3.h#L32)
```cpp
constexpr float dot(const Vector3& a, const Vector3& b) { return a.x * b.x + a.y * b.y + a.z * b.z; }
constexpr Vector3 cross(const Vector3& a, const Vector3& b) {
    return {a.y * b.z - a.z * b.y, a.z * b.x - a.x * b.z, a.x * b.y - a.y * b.x};
}
```

Толчок в точку тела меняет его скорость и закручивает его. Это решатель контактов делает тысячи раз за шаг, и снова работает векторное произведение:

[src/rigid/RigidWorld.h:151](../../src/rigid/RigidWorld.h#L151)
```cpp
void applyImpulse(int i, const Vector3& J, const Vector3& p) {
    RigidBody& b = bodies_[i];
    if (b.invMass == 0) return;
    b.vel += J * b.invMass;
    b.angVel += b.applyInvInertiaWorld(cross(p - b.pos, J));
}
```

Круг заряда в тесте считается поворотом Бориса (Boris 1970). Скорость поворачивается двумя векторными произведениями и не меняет длину, как и в природе:

[tests/MathBookTests.cpp:158](../../tests/MathBookTests.cpp#L158)
```cpp
const Vector3 vPrime = v + cross(v, t);              // 2. turn once by t ...
v = v + cross(vPrime, s);                            // 3. ... and finish the turn by s
x = x + v * float(h);                                // 4. move
```

## Тест

`RF_TEST="mathbook: vectors"` ([MathBookTests.cpp:141](../../tests/MathBookTests.cpp#L141)) печатает:

| Величина | Расчёт | Теория |
|---|---|---|
| радиус круга заряда | от 1,00000 до 1,00063 м | 1 м |
| скорость заряда после 200 шагов | 1,0000004 м/с | 1 м/с: магнитная сила работы не совершает |
| угловая скорость ящика после толчка сбоку | (0; 0; 1,1250) рад/с | $\mathbf I^{-1}(\mathbf r\times\mathbf J)$, ошибка 0 |

**Урок, найденный этим тестом.** Положение и скорость в этой схеме живут в разные моменты времени: положение на целых шагах, скорость посередине между ними. Сначала тест начинал обе величины в один момент, и весь круг съезжал вбок на полшага: радиус от старого центра гулял от 0,975 до 1,025 м. Когда скорость начали на полшага раньше, радиус стал точным до $6\cdot10^{-4}$. Это называется схемой «чехарда» (leapfrog).

## Физика

- **Твёрдые тела.** Каждый контакт — это толчок в точку, и векторное произведение решает, закрутится ли тело ([глава 2 документации](../02-rigid-bodies.md)).
- **Плазма.** Сила Лоренца $\mathbf J\times\mathbf B$ держит плазму в магнитосфере и в токамаке ([глава 6 документации](../06-mhd-plasma.md)).
- **Вихри.** Ротор поля скоростей строится из векторных произведений ([глава 7](07-fields.md)).

## Проверь сам

Откройте дверь, толкая её у ручки, а потом у самых петель. Сила та же, а плечо $\mathbf r$ в десять раз короче, и момент $\mathbf r\times\mathbf F$ в десять раз меньше. Дверь еле двигается.
