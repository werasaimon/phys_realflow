# 7. Поля: градиент, дивергенция, ротор

[← Кватернионы и повороты](06-quaternions.md) · [Тензоры →](08-tensors.md)

## Идея

**Поле** — это число или стрелка в каждой точке пространства. Температура в комнате — поле чисел. Ветер — поле стрелок. Газ, дым, огонь и магнитное поле в движке — это поля на сетке.

У полей есть три главных вопроса, и на каждый свой ответ:

- **Градиент — «куда в гору».** Для поля чисел, например высоты на карте, градиент — стрелка в сторону самого крутого подъёма. Длина стрелки — крутизна склона. Газ течёт от высокого давления к низкому, то есть против градиента давления.
- **Дивергенция — «сколько вытекает».** Для поля стрелок это число в каждой точке: сколько втекает в маленький кубик и сколько вытекает. Положительная — источник, как кран. Отрицательная — сток, как слив в раковине. Воду сжать нельзя, поэтому сколько втекло, столько и вытекло: дивергенция её скорости равна нулю везде.
- **Ротор — «как закручивает».** Опустите в поток маленькую вертушку. Если она крутится, у поля есть ротор. Ось вращения вертушки — направление ротора, скорость вращения — его длина.

## Картинка из движка

![Дивергенция скорости до и после проекции давлением](../img/math/divergence.svg)

Тест задаёт газу скорость, которая «сжимает» газ: слева газ сходится, справа расходится. Синие точки — дивергенция вдоль среднего ряда сетки до шага, до 3 1/с. Затем газ делает один крошечный шаг. Давление находит ту часть скорости, которая сжимает, и вычитает её. Оранжевые точки — дивергенция после: ноль по всей длине, до $2\cdot10^{-4}$ 1/с.

## Формула

$$
\nabla p = \Big(\frac{\partial p}{\partial x},\ \frac{\partial p}{\partial y},\ \frac{\partial p}{\partial z}\Big),
\qquad
\nabla\cdot\mathbf u = \frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} + \frac{\partial w}{\partial z},
\qquad
\nabla\times\mathbf B = \Big(\frac{\partial B_z}{\partial y} - \frac{\partial B_y}{\partial z},\ \dots\Big).
$$

Проекция давлением (Chorin 1968) — рецепт из трёх шагов:

1. Шагнуть скорость без давления: получится $\mathbf u^*$, у которой $\nabla\cdot\mathbf u^* \ne 0$.
2. Найти давление из уравнения Пуассона $\nabla\cdot\big(\tfrac{\Delta t}{\rho}\nabla p\big) = \nabla\cdot\mathbf u^*$ ([глава 5](05-matrices.md)).
3. Вычесть градиент: $\mathbf u = \mathbf u^* - \tfrac{\Delta t}{\rho}\nabla p$. Теперь $\nabla\cdot\mathbf u = 0$.

Два тождества, верных для любого поля, держат на себе всю электродинамику: $\nabla\cdot(\nabla\times\mathbf A) = 0$ и $\nabla\times(\nabla\varphi) = 0$. Первое значит, что если магнитное поле $\mathbf B = \nabla\times\mathbf A$ получено как ротор, у него никогда не будет «магнитных зарядов».

## Код

На сетке MAC скорости хранятся на гранях клеток, и дивергенция клетки — это сумма того, что вытекает через шесть граней, делённая на размер клетки:

[src/gas/GasDebugDraw.cpp:134](../../src/gas/GasDebugDraw.cpp#L134)
```cpp
float GasSolver::cellDivergence(int i, int j, int k) const {
    const float du = u_.at(i + 1, j, k) - u_.at(i, j, k);
    const float dv = v_.at(i, j + 1, k) - v_.at(i, j, k);
    const float dw = w_.at(i, j, k + 1) - w_.at(i, j, k);
    return (du + dv + dw) / dx_;
}
```

Проекция целиком — [PressureSolver.cpp:22](../../src/gas/PressureSolver.cpp#L22), вычитание градиента — [PressureSolver.cpp:303](../../src/gas/PressureSolver.cpp#L303).

Ток — ротор магнитного поля, $\mathbf J = \nabla\times\mathbf B/\mu_0$. Движок считает его на рёбрах клеток ([MagneticField.cpp:145](../../src/plasma/MagneticField.cpp#L145)). Магнитное поле живёт на гранях и меняется по закону Фарадея через ротор электрического поля на рёбрах ([MagneticField.cpp:214](../../src/plasma/MagneticField.cpp#L214)). Из-за этого расположения сумма потоков через грани каждой клетки не меняется, и $\nabla\cdot\mathbf B = 0$ держится до округления сам собой. Метод называется constrained transport (Evans, Hawley 1988).

## Физика

- **Газ, дым, огонь.** Несжимаемость $\nabla\cdot\mathbf u = 0$ и проекция давлением — сердце всего газового решателя ([глава 4 документации](../04-gas-navier-stokes.md)).
- **Магнитное поле.** $\nabla\cdot\mathbf B = 0$ и $\mathbf J = \nabla\times\mathbf B/\mu_0$ — основа МГД ([глава 6 документации](../06-mhd-plasma.md)).
- **Вихри.** Ротор скорости, завихрённость, показывает вихревую дорожку за цилиндром, по которой меряют число Струхаля ([глава 9 документации](../09-benchmarks.md)).

## Проверь сам

Насыпьте на воду в тазу немного молотого перца и уберите руку. Где перец расходится во все стороны, там снизу поднимается поток: на поверхности это «источник». Потом помешайте воду пальцем по кругу. Щепка в центре водоворота начнёт вращаться: это ротор.
