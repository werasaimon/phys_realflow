# Поздняя энергия цепи: графики 2026-10-01

Источник — [протокол C++-зондов](../../book/evidence/chain-jitter-20261001/README.md),
SDK `18c1e1f`, Release, `RF_STRICT_FP=OFF`, сцена 40, сон выключен.
Все траекторные прогоны содержат 1800 кадров по 1/60 с и 40 подшагов.
«Кандидат RP3D» — наш изолированный вариант нулевых split-строк,
не запуск библиотеки RP3D. Он не перенесён в основной SDK.

| Рисунок | Данные и смысл |
|---|---|
| [rest-kinetic.svg](rest-kinetic.svg) | `rest.csv`, `rp3-rest.csv`, `rp3-iter24-rest.csv`; T на 10–30 с и увеличение 20–30 с |
| [positive-energy.svg](positive-energy.svg) | Те же три режима без захвата и после него; показана только max(ΔE, 0), отрицательная часть исключена |
| [frame-785-budget.svg](frame-785-budget.svg) | `counterfactual-785.csv`; сумма приращений фактических стадий и отдельный итог T/U/E |
| [split-energy.svg](split-energy.svg) | Схема измеренного механизма выбранных кадров; пунктир — гипотеза, причинный вклад не изолирован |

Энергетические приращения берутся из столбцов, вычисленных в double **до**
сериализации. Округлённые значения `total_J` не вычитаются. Локальная
альтернатива `split-counterfactual` исключена из суммы фактических стадий.
Графики не доказывают непрерывного непроникновения или точного равновесия.
Старые [минутные графики](../chain-relaxation/kinetic.svg) остаются результатами
опыта 2026-09-30 с другим протоколом.

Перестроение из корня репозитория требует Gnuplot и Graphviz:

```sh
sh tools/plot_chain_jitter.sh
```

Физика при этом не запускается. Генератор графиков —
[plot_chain_jitter.gnuplot](../../../tools/plot_chain_jitter.gnuplot),
исходник схемы — [split-energy.dot](split-energy.dot).
Обвязка [plot_chain_jitter.sh](../../../tools/plot_chain_jitter.sh) также
нормализует пробелы в SVG для Git, не меняя данные или геометрию рисунков.
[manifest.json](manifest.json) содержит хеши входных CSV, генераторов и SVG.
`plot-values.txt` сохраняет численную сверку суммы стадий и локального вклада split.
