# 11. Согласованный шаг: откат и повторное интегрирование

[Оглавление](README.md) · [Геометрический CCD](09-ccd-contract.md) · [Достоверность для робота](10-robotics-validation.md)

Дата: **2026-10-01**. Исправлена воспроизводимая причина переполнения энергии:
ограничение ориентации после интегрирования при сохранении конечной угловой скорости.
Это применение известного принципа восстановления состояния, а не заявление
научной новизны или универсальной безошибочности.

## Почему ограничение позы создавало энергию

Для угловой скорости в мировой системе координат

\[
T_r(q,\omega)=\tfrac12\omega^T I(q)\omega,
\qquad I(q)=R(q)I_bR(q)^T.
\]

Прежний CCD заменял конечную ориентацию \(q_1\) на промежуточную \(q_s\), оставляя
\(\omega_1\). Поэтому без контактного импульса появлялась добавка

\[
\Delta T_r=\tfrac12\omega_1^T[I(q_s)-I(q_1)]\omega_1.
\]

Её знак не ограничен. В [сохранённой трассе](evidence/ccd-20261001/mixed_trace_clamp-output.txt)
тело 32 за одну такую операцию получало **1706.265 → 4135.717 Дж**.
Сохранение одного мирового момента импульса при произвольной замене ориентации
также не гарантирует сохранение энергии. Искусственное обнуление скорости
скрывало бы дефект, меняя динамику.

## Реализация через объекты

- [RigidStep](../../src/rigid/RigidStep.cpp) управляет пробами и принятым временем.
- [RigidStepCheckpoint](../../src/rigid/RigidStepCheckpoint.cpp) сохраняет тела,
  нагрузки, контактные кэши, состояние суставов, захвата мышью, сна и островов.
  Объекты суставов сохраняют адреса. Broad phase повторно получает восстановленные
  границы; его внутреннее дерево не обязано совпадать до бита.
- [TimeOfImpact](../../src/rigid/TimeOfImpact.cpp) проверяет пробное движение,
  не меняя позы и скорости. Его результат определяет повтор, а не интерполяцию позы.

Обозначим пробный шаг импульсного решателя через \(\Phi_{h;H}\), где \(H\) —
неизменный внешний интервал, а \(h\) — длительность пробы.
Для принятой пробы возвращаем \(\Phi_{h;H}(z)\). Для отклонённой восстанавливаем \(z\)
и вычисляем рекурсивно два полушага:

\[
\Psi_{h;H}(z)=\Psi_{h/2;H}\bigl(\Psi_{h/2;H}(z)\bigr).
\]

Восстанавливается **весь мир**, поскольку импульсы связывают тела.
Оба полушага заново строят контакты и решают ограничения. Если даже поздний
полушаг не удаётся, откатывается весь исходный вызов, включая ранее принятые части.
Двоичное деление исключает микрошаг из-за накопленной ошибки вычитания остатка.
Разделение допускается только при представимом равенстве двух половин исходному шагу.
Выбор шага зависит от состояния: симплектичность свободного вращения сама по себе
не означает симплектичности всего адаптивного контактного интегратора.

Силы и моменты, заданные перед вызовом, считаются постоянными на его интервале:
для свободного тела \(\Delta p=F\sum h_i=Fh\), \(\Delta L=\tau h\).
Они восстанавливаются перед каждым подшагом, расходуются после успеха и сохраняются
после отказа. Это предположение о внешнем воздействии, а не модель изменения силы
контроллера внутри интервала.

Позиционная коррекция также должна уменьшаться при делении шага. Прежняя
скорость восстановления проникновения \(v_b=\beta\max(d-s,0)/h\) даёт перемещение
\(h v_b=\beta\max(d-s,0)\), не зависящее от длительности пробы. Это создавало
повторяемый отказ в первом кадре теста 150 тел в жидкости: исходное перекрытие
выталкивало тело в соседа при любом числе делений. При внешнем интервале \(H\)
теперь используем \(v_b=\beta\max(d-s,0)/H\); перемещение коррекции равно \(h v_b\)
и стремится к нулю вместе с \(h\). Без повторов \(h=H\), прежняя формула сохраняется.
Это численная стабилизация геометрии, не закон упругости материала; при нескольких
принятых частях итоговое восстановление может отличаться, поскольку глубина
пересчитывается. В режиме split impulse она не является контактным импульсом
физической скорости. Тест с тремя сферами проверяет деление и нулевую кинетическую
энергию такого восстановления; исходный отказ общего набора сохранён в отчёте.

Восстановление и перезапуск интегрирования у разрыва обсуждаются у
[Mirtich, Timewarp Rigid Body Simulation, 2000, §2.1–2.2](https://graphics.stanford.edu/courses/cs448-01-spring/papers/mirtich.pdf).
У нас синхронное деление общего шага; асинхронный Timewarp не реализован.
[Rigid IPC, 2021, §2.1](https://ipc-sim.github.io/rigid-ipc/assets/rigid_ipc_paper_350ppi.pdf)
обсуждает ограничения явных консервативных методов и использует другой,
неявный барьерный подход. Наш повтор не наследует гарантий IPC.

## Контракт вызова и отказа

```cpp
world.params.ccd = true;
world.params.ccdAllMoving = true;
world.params.ccdMaxSubdivisions = 16;
if (world.tryStep(h)) {
    simulationTime += world.lastStepResult().acceptedDt;
} else {
    // State and pending loads are restored. Handle the failure; do not advance time.
    const auto reason = world.lastStepResult().status;
    // Stop this calculation or select an explicitly justified numerical policy.
}
```

| Результат | Смысл |
|---|---|
| `Completed` | Принят весь запрошенный интервал; это не сертификат точности |
| `InvalidInput` | Неположительный или неконечный шаг времени |
| `Unresolved` | Запрос CCD не завершён при нулевом бюджете итераций |
| `SubdivisionLimit` | Не хватает глубины, бюджета 1024 проб или представимости половин |
| `NonFinite` | Неконечное состояние не устранено доступным делением |

`step(h)` вызывает тот же механизм и при отказе бросает `std::runtime_error`.
Новый отказ должен обрабатываться приложением. Атомарность относится к одному
`RigidWorld::tryStep`, **не ко всему кадру `Simulation`**: предыдущие подшаги,
частицы, газ и внешние callbacks могли уже измениться. После исключения нельзя
просто продолжать такой кадр; для этого нужна отдельная транзакция фасада.
Существующий редактор не получает в этой правке нового обработчика исключений.

Откат включён для последовательных импульсов с CCD. При отключённом CCD и в XPBD
сохраняется прежний интегратор без этого механизма. Исключения выделения памяти
не являются контролируемыми численными отказами данной транзакции.

`acceptedSubsteps` и `rejectedTrials` описывают работу вызова; при отказе число
принятых частей и `acceptedDt` равны нулю. `maxContactDepth` — максимум глубины
**многообразий** по принятым частям. Счётчики CCD включают отклонённые пробы,
таймеры — повторную работу и сохранение состояния (`rigid/checkpoint ms`).
Глобальная диагностика `Probe`, включая отладочные рисунки проб, не откатывается.
`lastStepDt()` и контактные импульсы относятся к последней принятой части,
а не к усреднённой силе всего внешнего интервала.
Старый параметр `ccdMaxPasses` сохранён для совместимости и больше не используется.

## Два режима отбора движений

По умолчанию SDK сохраняет порог `ccdAllMoving=false`. Тело, движущееся медленнее
порога относительно собственного размера, может проникнуть в тонкую стену.
В регрессии куб после удара пули проникал на **21.618 мм**, оставаясь ниже порога.
Деление шага само по себе этот пропуск не устраняет.

В демонстрации `RigidCcd` теперь включён `ccdAllMoving=true`: проверяются все
движущиеся активные тела. Остальные сцены сохраняют прежнюю настройку.
Для задач с тонкими препятствиями следует явно выбирать этот режим и проверять
его вычислительную стоимость на своей геометрии. Начальный контакт всё равно
передаётся дискретному решателю; включение всех движений не является сертификацией.

## Воспроизводимая проверка

[Тесты](../../tests/RigidStepTests.cpp) запускают смешанную сцену на 2 с
при трёх шагах и в обоих режимах отбора. Порог приёмки: конечная энергия,
пик не выше начального более чем на 5%, завершение каждого шага;
для всех движений — глубина многообразий и независимая проверка грани стены
менее 2 мм. Допуски не подгонялись по результату.

| Отбор | Шаг, с | Макс. глубина многообразий, мм | Конечная энергия, Дж |
|---|---:|---:|---:|
| По скорости | 1/600 | 6.27652 | 364.552 |
| По скорости | 1/1200 | 21.6183 | 372.931 |
| По скорости | 1/2400 | 3.04490 | 389.110 |
| Все движения | 1/600 | 0.602379 | 370.695 |
| Все движения | 1/1200 | 0.601508 | 372.688 |
| Все движения | 1/2400 | 0.316404 | 411.862 |

Во всех шести прогонах пик полной механической энергии на границах внешних шагов
равен начальной **204366.895 Дж**. Внутри каждой пробы проверяется конечность
состояния; эти наблюдения не доказывают монотонность энергии между выборками.
Независимая проверка стены использует её плоскости и границы тел, полностью
попадающих в поперечный размер стены. Максимум в режиме всех движений —
**0.001133 мм** на границах внешних шагов. Это частичный геометрический оракул:
он не охватывает края стены, остальные пары и весь непрерывный путь.

Дополнительно проверяются аналитический импульс силы и момента, момент импульса
свободного несимметричного тела, отказ после успешного первого полушага,
восстановление нагрузок и последующее совпадение с нетронутым контрольным миром,
некорректный шаг времени и сохранение ссылок на суставы.
Проверка центрального удара равных масс с переносом системы отсчёта на 99 м/с
даёт тот же импульс, что и без переноса: учитывается относительная скорость.
Результаты и сопоставление с MuJoCo — в [главе 12](12-mujoco-continuous-collision.md).
Исходный расширенный набор дал **44/45**: единственный провал — остановка
балки за 2 с. В этой точке поступательная скорость уже около 5·10⁻⁷ м/с,
угловая — 2.17659 рад/с; к 2.5 с она падает примерно до 1.5·10⁻¹⁰ рад/с.
Горизонт именно этой проверки увеличен до **3 с**, остальные пределы сохранены.
Это пересмотр эмпирического срока успокоения, а не исправление решателя
или доказательство более точной траектории. Исходный провал сохранён; новая
проверка прошла отдельно.

Команды, журналы и результаты общих регрессий — в
[пакете доказательств](evidence/ccd-retry-20261001/README.md).

## Что остаётся нерешённым

Первый внешний упругий benchmark выявил потерю энергии при локальном
дроблении даже без CCD: интегратор свободного полёта и поправка restitution
не согласованы для переменного шага. Результаты и воспроизводимый контрольный
опыт — в [главе 13](13-external-benchmark.md). Исправление ориентационного
нагрева через атомарный откат не устранило этот отдельный дефект.

Нельзя объявлять гарантированным произвольное движение: есть исходные перекрытия,
дискретная модель начального контакта, короткая интерполяция вращения между позами,
позиционные поправки суставов после CCD и несертифицированная арифметика `float`.
Отказ с откатом честно останавливает расчёт, но не гарантирует продвижения времени.
Различие конечных энергий при сгущении шага ещё не доказывает сходимость траектории.

Данные реального робота, калибровка материалов и приводов, область условий и
допуски нужны для следующего этапа: [валидации операции](10-robotics-validation.md).
Исправленный численный дефект не подтверждает пригодность для управления роботом
стоимостью $1 000 000.
