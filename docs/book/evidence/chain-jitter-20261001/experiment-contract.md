# Критерии A/B до переноса в SDK

Гипотеза: коррекция поз создаёт часть позднего роста энергии. Для кадра 785
сравниваются дрейфы из одинакового состояния с bias и без bias; альтернативный
дрейф не передаётся следующему подшагу. Обычный шаг должен совпасть по хешу
поз и физических скоростей с разбором по стадиям во всех 40 подшагах.

A/B: beta 0.20 → 0.05; отдельно 12 → 24 итерации. Для каждого — 30 с без
захвата и с одним стандартным захватом. Не меняются сон, трение, damping и CCD.
Метрики после 10 с: максимум положительного ΔE за кадр, максимум T, движение
за кадр, средняя T последней секунды. Инварианты: конечность, ноль разрывов,
глубина контактов не хуже 0.11 мм в этих сценариях. Ни один удачный эпизод
не достаточен для нового значения по умолчанию; нужны отдельные регрессии
колеса, привода, гайки и стеков и чувствительность к шагу.
