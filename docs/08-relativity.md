# 8. Свет и движение у чёрной дыры: общая теория относительности

[← МГД и плазма](06-mhd-plasma.md) · [Оглавление](README.md)

**Что это и зачем.** Модуль `relativity/` — пространство-время Керра (вращающаяся чёрная дыра; при $a = 0$ — Шварцшильд), геодезические света и пробных тел как гамильтонова система, и эталонный трассировщик лучей на CPU: что именно увидит наблюдатель у горизонта. Это **физика**, а не картинка: каждая величина здесь имеет точный ответ из ОТО, и тесты сверяются с ним — отклонение луча, фотонная сфера, ISCO, прецессия перигелия, тень дыры, инварианты Нётер и Картера вдоль луча. Шейдер редактора — только исполнитель того же алгоритма на GPU; его правильность проверяется попиксельно против кадра, посчитанного здесь.

> **Статус главы.** Первый этап: метрика, геодезические (RK4 / RK45), тетрада ZAMO, трассировщик с небом-шахматкой и тонким кеплеровским диском, шесть тестов. Дальше по плану: симплектический интегратор (ограниченная ошибка на $10^6$ витков), координаты Керра–Шильда, ОТО-МГД плазмы у горизонта (уровень кодов EHT), перенос излучения по геодезическим, максимальное расширение Шварцшильда (мост Эйнштейна–Розена). Единицы геометрические, $G = c = 1$: длины и времена в массах $M$ (Солнце: $M = 1{,}48$ км $= 4{,}9$ мкс; M87*: $9{,}6\cdot10^{12}$ м). Всё в `double`.

## 8.1 Метрика Керра

В координатах Бойера–Линдквиста $(t, r, \theta, \varphi)$ (Bardeen, Press & Teukolsky 1972; MTW §33.2), $\Sigma = r^2 + a^2\cos^2\theta$, $\Delta = r^2 - 2Mr + a^2$:

$$
ds^2 = -\Bigl(1 - \frac{2Mr}{\Sigma}\Bigr)dt^2 - \frac{4Mar\sin^2\theta}{\Sigma}\,dt\,d\varphi + \frac{\Sigma}{\Delta}dr^2 + \Sigma\,d\theta^2 + \Bigl(r^2 + a^2 + \frac{2Ma^2 r\sin^2\theta}{\Sigma}\Bigr)\sin^2\theta\,d\varphi^2 .
$$

Горизонт — больший корень $\Delta$: $r_+ = M + \sqrt{M^2 - a^2}$. Это координатная особенность: $t \to \infty$ на горизонте. Для падения сквозь него (и для будущей ОТО-МГД) нужны проникающие координаты — при $a = 0$ реализованы входящие координаты Эддингтона–Финкельштейна $v = t + r + 2M\ln(r/2M - 1)$:

$$
ds^2 = -\Bigl(1 - \frac{2M}{r}\Bigr)dv^2 + 2\,dv\,dr + r^2 d\Omega^2 ,
$$

конечные на $r = 2M$ (Finkelstein 1958).

[src/relativity/Metric.cpp:20](../src/relativity/Metric.cpp#L20)
```cpp
    const double Sigma = r * r + a * a * c * c;
    const double Delta = r * r - 2.0 * M * r + a * a;
    g[0][0] = -(1.0 - 2.0 * M * r / Sigma);
    g[0][3] = g[3][0] = -2.0 * M * a * r * s2 / Sigma;
    g[1][1] = Sigma / Delta;
    g[2][2] = Sigma;
    g[3][3] = (r * r + a * a + 2.0 * M * a * a * r * s2 / Sigma) * s2;
```

Из той же статьи — круговые орбиты в экваториальной плоскости: фотонная $r_{ph} = 2M\{1 + \cos[\tfrac23\arccos(\mp a/M)]\}$ ($3M$ при $a = 0$), последняя устойчивая ISCO через $Z_1, Z_2$ ($6M$ при $a = 0$), энергия и момент круговой орбиты массивной частицы (ур. 2.12–2.13), кеплерова $\Omega = \pm\sqrt M/(r^{3/2} \pm a\sqrt M)$.

## 8.2 Геодезические как гамильтонова система

Луч или свободная частица — восемь переменных $(x^\mu, p_\mu)$ с гамильтонианом $H = \tfrac12 g^{\mu\nu}p_\mu p_\nu$ (Carter 1968; так интегрируют GYOTO и DNGR):

$$
\frac{dx^\mu}{d\lambda} = g^{\mu\nu}p_\nu, \qquad \frac{dp_\mu}{d\lambda} = -\frac12\,\frac{\partial g^{\alpha\beta}}{\partial x^\mu}\,p_\alpha p_\beta .
$$

$H = 0$ для света и $-\tfrac12$ для частицы единичной массы, $\lambda$ — собственное время частицы. Производные $g^{\mu\nu}$ берутся пятиточечной центральной разностью по $r$ и $\theta$ (по $t$ и $\varphi$ метрика не зависит — производные нули, и $E = -p_t$, $L = p_\varphi$ сохраняются **точно**, до округления). Шаг разности $10^{-4}r$, у горизонта — не больше пятой части зазора до $r_+$: шаблон не должен заступать за координатную особенность (иначе луч в координатах Бойера–Линдквиста численно «отскакивает» от горизонта).

[src/relativity/Geodesic.cpp:38](../src/relativity/Geodesic.cpp#L38)
```cpp
void Geodesic::derivative(const GeodesicState& s, double dx[4], double dp[4]) const {
    double ginv[4][4], dg[4][4][4];
    contravariantDerivatives(s.x, ginv, dg);
    for (int mu = 0; mu < 4; ++mu) {
        dx[mu] = 0.0;
        for (int nu = 0; nu < 4; ++nu) dx[mu] += ginv[mu][nu] * s.p[nu];
    }
    for (int k = 0; k < 4; ++k) {
        double sum = 0.0;
        for (int a = 0; a < 4; ++a)
            for (int b = 0; b < 4; ++b) sum += dg[k][a][b] * s.p[a] * s.p[b];
        dp[k] = -0.5 * sum;
    }
}
```

Два интегратора: классический RK4 с фиксированным шагом и Дорманд–Принс RK5(4) с контролем шага. Настоящая мера точности — постоянная Картера

$$
Q = p_\theta^2 + \cos^2\theta\Bigl(a^2(\mu^2 - E^2) + \frac{L^2}{\sin^2\theta}\Bigr),
$$

сохраняющаяся благодаря скрытой симметрии Керра: она требует правильного движения по $r$ и $\theta$. Её дрейф — ошибка интегратора и ничего больше (таблица ниже). У RK45 с допуском $10^{-12}$ он $6\cdot10^{-10}$ за 20 000 $M$; у RK4 с шагом $2M$ — $8\cdot10^{-6}$, и растёт со временем. Следующий шаг — симплектический интегратор: ошибка ограничена, а не накапливается (обратный анализ ошибок, Hairer–Lubich–Wanner; явные симплектические схемы для Керра — Wu, Wang, Huang 2021).

**Что видит наблюдатель.** Направление в собственной системе наблюдателя переводится в 4-импульс через ортонормированную тетраду ZAMO (Bardeen, Press & Teukolsky 1972, ур. 3.3) — наблюдателя, увлекаемого вращением пространства: $e_t = (\partial_t + \omega\,\partial_\varphi)/\alpha$, $e_i = \partial_i/\sqrt{g_{ii}}$, где $\alpha = 1/\sqrt{-g^{tt}}$, $\omega = -g_{t\varphi}/g_{\varphi\varphi}$; при $a = 0$ это статический наблюдатель.

[src/relativity/Geodesic.cpp:180](../src/relativity/Geodesic.cpp#L180)
```cpp
    const double alpha = 1.0 / std::sqrt(-ginv[0][0]);
    const double omega = -g[0][3] / g[3][3];
```

## 8.3 Трассировщик: тень, небо и диск

Для каждого пикселя камеры в $(r_0, \theta_0, \varphi_0)$ строится импульс *пришедшего* фотона и геодезическая интегрируется **назад** по $\lambda$ — туда, откуда свет пришёл: на небо (шахматка $15^\circ$ по $\theta, \varphi$, чтобы линзирование было видно), в дыру (чёрное), или на тонкий экваториальный диск между ISCO и $r_{out}$. Луч, падающий внутрь ниже самой внутренней (проградной) фотонной орбиты, точки поворота уже не имеет — он в дыре; интегрирование останавливается там, а не на горизонте, где координаты Бойера–Линдквиста заставили бы дробить шаг. Обратный ход, а не «переворот скорости»: в метрике Керра обращение времени меняет знак $a$, и путь фотона в обратную сторону — не тот же путь.

Яркость диска — фактор красного смещения кеплеровского газа для далёкого наблюдателя (Cunningham 1975):

$$
g = \frac{E}{u^t\,(E - \Omega L)}, \qquad u^t = \frac{1}{\sqrt{-(g_{tt} + 2\Omega g_{t\varphi} + \Omega^2 g_{\varphi\varphi})}},
$$

наблюдаемая интенсивность $g^4$ от излучённой ($I_\nu/\nu^3$ — инвариант: $g^3$ на единицу частоты и ещё $g$ за ширину полосы); излучательная способность здесь — игрушечная $(r_{in}/r)^3$, настоящая — Новиков–Торн 1973.

[src/relativity/RayTracer.cpp:72](../src/relativity/RayTracer.cpp#L72)
```cpp
        const double Omega = metric_.keplerianOmega(diskR, true);
        const double ut = 1.0 / std::sqrt(-(g[0][0] + 2.0 * Omega * g[0][3] + Omega * Omega * g[3][3]));
        const double E = -s.p[0], L = s.p[3];
        const double gf = E / (ut * (E - Omega * L));
```

Тень невращающейся дыры — диск углового радиуса $3\sqrt3\,M/r_0$ (Bardeen 1973): критический прицельный параметр фотонной сферы. Тест меряет её по кадру $96\times96$ подсчётом чёрных пикселей. Ускорение, а не гравитация, даёт «рыбий глаз»: это аберрация $\cos\theta' = (\cos\theta + \beta)/(1 + \beta\cos\theta)$ — она войдёт в камеру движущегося наблюдателя следующим шагом; «увидеть свой затылок» — свойство фотонной сферы, и тест ниже показывает её числом.

Ограничения честно: метрика фиксирована (пробные лучи и тела, никакого обратного влияния), диск — тонкий кеплеровский с игрушечной излучательной способностью, координаты Керра–Шильда для вращающейся дыры и симплектический интегратор — впереди; квантовой гравитации здесь нет и не будет — полуклассика (температура Хокинга, эффект Унру) появится как формулы, а не как модель.
