# 11. Действие: откуда берутся уравнения

[← Верификация](10-verification.md) · [Оглавление](README.md)

**Что это и зачем.** Каждое уравнение, которое решает SDK, можно получить из одной формулы: **действия**. Эта глава выписывает действие для каждой физики, выводит из него уравнения, показывает, как наша численная схема обходится с этим действием, даёт ссылку на строку кода и график из настоящего прогона. И честно говорит, где модель неверна.

Для любопытного школьника. Бросьте мяч вверх. Он мог бы долететь до той же точки в тот же момент тысячей путей: быстрее вверх и медленнее вниз, зигзагом, по кругу. Природа выбирает один путь, и его можно найти, не зная сил. Сложите по всему пути «энергию движения минус энергию положения». У настоящего пути эта сумма не меняется при малом изменении пути: он стоит на «плоском месте», как шарик на дне ямки или на вершине горки. Эта сумма и есть действие. Из одного этого правила выходят законы Ньютона, уравнения жидкости, магнитного поля и движения света около чёрной дыры.

Для физика. Везде ниже используются принцип Гамильтона, теорема Нётер, множители Лагранжа для связей, принцип Лагранжа–Даламбера с функцией Рэлея для диссипации и дискретная механика Марсдена–Уэста для численных схем. У каждой физики шесть частей в одном порядке:

| Часть | Что в ней |
|---|---|
| **Действие** | одна формула и её симметрии |
| **Уравнения** | вариация, уравнение Эйлера–Лагранжа, инварианты Нётер, функция Рэлея для диссипации |
| **Дискретизация** | как непрерывное действие становится нашим шагом и что теряется |
| **Код** | строки, которые решают каждое уравнение |
| **Графики** | настоящие прогоны тестов, не рисунки от руки |
| **Границы** | где модель неверна, с числом, если оно есть |

Графики строятся так: тесты из [tests/ActionTests.cpp](../tests/ActionTests.cpp) пишут CSV, скрипт [tools/plot_action.py](../tools/plot_action.py) рисует из них SVG (раздел [11.11](#1111-как-пересобрать-графики)).

## 11.1 Принцип и его инструменты

### Действие и принцип Гамильтона

Состояние системы задают обобщённые координаты $q(t)$: положения частиц, углы, значения поля в точках. **Лагранжиан** $L(q, \dot q, t)$ для механики равен $T - V$, кинетическая энергия минус потенциальная. **Действие** пути от $t_0$ до $t_1$:

$$
S[q] = \int_{t_0}^{t_1} L\big(q(t), \dot q(t), t\big)\,dt .
$$

**Принцип Гамильтона:** настоящее движение между двумя заданными положениями делает $S$ стационарным: $\delta S = 0$ при любых малых вариациях $\delta q(t)$ с $\delta q(t_0) = \delta q(t_1) = 0$.

### Уравнения Эйлера–Лагранжа

Вариация действия, после интегрирования по частям:

$$
\delta S = \int_{t_0}^{t_1}\Big(\frac{\partial L}{\partial q} - \frac{d}{dt}\frac{\partial L}{\partial \dot q}\Big)\delta q\,dt = 0
\quad\Longrightarrow\quad
\frac{d}{dt}\frac{\partial L}{\partial \dot q} = \frac{\partial L}{\partial q}.
$$

Для частицы $L = \tfrac12 m|\dot{\mathbf x}|^2 - V(\mathbf x)$ это $m\ddot{\mathbf x} = -\nabla V$, второй закон Ньютона. Для поля $q$ заменяется функцией точки, сумма по частицам заменяется интегралом по объёму, и получаются уравнения в частных производных.

### Теорема Нётер: симметрия даёт сохранение

Если лагранжиан не меняется при сдвиге $q \to q + \varepsilon\,\xi(q)$, то величина $J = \frac{\partial L}{\partial \dot q}\cdot\xi$ сохраняется. Если $L$ не зависит от времени явно, сохраняется энергия $E = \dot q\cdot\frac{\partial L}{\partial\dot q} - L$ (Noether 1918). Каждая строка таблицы проверена тестом:

| Симметрия действия | Что сохраняется | Тест |
|---|---|---|
| сдвиг во времени | энергия | `Noether: energy, momentum and angular momentum of rigid bodies`, `action: a free spinning box keeps its energy and L (Noether)` |
| сдвиг в пространстве | импульс | `Noether: …` (скользящий удар), `magnets: two free magnets pull together, momentum conserved` |
| поворот | момент импульса | `Noether: …`, `action: a free spinning box…` |
| сдвиг по $t$ и по $\varphi$ в метрике Керра | $E = -p_t$, $L_z = p_\varphi$ | `geodesics: E, L and Carter's Q along a Kerr orbit` |
| скрытая симметрия Керра (тензор Киллинга) | постоянная Картера $Q$ | тот же тест |

### Связи: множители Лагранжа

Связь $C(q) = 0$ (сустав, нерастяжимая нить, несжимаемость) входит в действие с **множителем Лагранжа** $\lambda$:

$$
S = \int \big(L - \lambda^{\mathsf T} C(q)\big)\,dt
\quad\Longrightarrow\quad
M\ddot q = -\nabla V - J^{\mathsf T}\lambda,\qquad J = \frac{\partial C}{\partial q}.
$$

$-J^{\mathsf T}\lambda$ есть сила реакции связи. Она **не совершает работы**: вдоль допустимого движения $J\dot q = \frac{d}{dt}C = 0$, поэтому мощность $-\lambda^{\mathsf T}J\dot q = 0$. Это проверяет тест маятника в [11.3](#113-сочленения-и-контакты): вся потеря энергии там идёт от затухания, сустав не отнимает ничего.

Для контакта связь односторонняя, $C \ge 0$ (тела не проникают). Тогда множитель тоже односторонний, и выполняются **условия дополнительности** Синьорини–Моро: $\lambda \ge 0$, $C \ge 0$, $\lambda\,C = 0$. Контакт только толкает и толкает только при касании.

### Диссипация: у трения нет действия

Трение, вязкость, электрическое сопротивление превращают движение в тепло **в одну сторону по времени**. Действие симметрично относительно обращения времени, поэтому чистого действия у диссипации нет. Её добавляют через **принцип Лагранжа–Даламбера**:

$$
\delta\int L\,dt + \int F\cdot\delta q\,dt = 0,\qquad F = -\frac{\partial R}{\partial \dot q},
$$

где $R(\dot q) \ge 0$ есть **функция Рэлея**. Если $R$ однородна степени $k$ по скоростям, то

$$
\frac{dE}{dt} = F\cdot\dot q = -\dot q\cdot\frac{\partial R}{\partial \dot q} = -k\,R .
$$

Для вязкого трения $R = \tfrac12 c\,|\dot q|^2$ ($k = 2$) энергия убывает со скоростью $2R$. Для сухого трения Кулона $R = \mu N|v|$ ($k = 1$) она убывает со скоростью $R = \mu N|v|$: ровно работа трения на пройденном пути. Это можно проверить тестом, и тесты этой главы проверяют именно такие балансы. Это строже, чем «энергия не растёт»: потерянная энергия должна совпасть с рассеянной по формуле Рэлея.

### Дискретное действие и вариационные интеграторы

Численная схема тоже может иметь действие. Вместо интеграла берётся сумма **дискретного лагранжиана** $L_d(q_k, q_{k+1}) \approx \int_{t_k}^{t_{k+1}} L\,dt$:

$$
S_d = \sum_k L_d(q_k, q_{k+1}),\qquad
\frac{\partial S_d}{\partial q_k} = D_2L_d(q_{k-1}, q_k) + D_1L_d(q_k, q_{k+1}) = 0 .
$$

Последнее равенство есть **дискретное уравнение Эйлера–Лагранжа**, оно и есть шаг схемы (Marsden & West 2001). Например, $L_d = h\big[\tfrac12 m\,|(q_{k+1}-q_k)/h|^2 - V(q_k)\big]$ даёт схему Стёрмера–Верле. Что получается даром:

- **Симплектичность.** Схема сохраняет фазовый объём, как настоящая механика.
- **Дискретная теорема Нётер.** Если $S_d$ симметрично, соответствующий импульс сохраняется **точно**, до округления, при любом шаге.
- **Энергия без векового дрейфа.** Обратный анализ ошибок: схема точно решает близкую систему с гамильтонианом $\tilde H = H + O(h^p)$. Поэтому ошибка энергии колеблется, но не накапливается экспоненциально долгое время (Hairer, Lubich, Wanner 2006).
- **Диссипация честно.** Дискретный принцип Лагранжа–Даламбера даёт схемы, где потеря энергии за шаг равна дискретной работе сил трения (Kane et al. 2000).

Не все наши схемы вариационные. Это не плохо само по себе: неявный Эйлер и полулагранжев перенос устойчивы там, где вариационная схема потребовала бы крошечного шага. Но у них есть лишняя, **численная** диссипация. В разделах ниже для каждой схемы сказано, вариационная ли она, и если нет, сколько энергии уходит лишнего.

## 11.2 Твёрдое тело

### Действие

Положение тела задаёт пара: центр масс $\mathbf x$ и поворот $R \in SO(3)$, то есть точка группы $SE(3)$. Угловая скорость в осях тела $\boldsymbol\Omega$ определяется из $\dot R = R\,[\boldsymbol\Omega]_\times$.

$$
S = \int \Big(\tfrac12 m\,|\dot{\mathbf x}|^2 + \tfrac12\,\boldsymbol\Omega\cdot\mathbf I\boldsymbol\Omega - m\,g\,y\Big)\,dt .
$$

$\mathbf I$ есть тензор инерции в главных осях тела (диагональный). Симметрии: сдвиг во времени; сдвиг по горизонтали; без тяжести ещё и любой сдвиг и любой поворот мира.

### Уравнения

Вариация по $\mathbf x$ даёт $m\ddot{\mathbf x} = m\mathbf g$. Вариация по повороту делается на группе: $\delta R = R\,[\boldsymbol\eta]_\times$ и $\delta\boldsymbol\Omega = \dot{\boldsymbol\eta} + \boldsymbol\Omega\times\boldsymbol\eta$. Уравнение Эйлера–Пуанкаре для свободного тела есть уравнение Эйлера:

$$
\mathbf I\,\dot{\boldsymbol\Omega} + \boldsymbol\Omega\times\mathbf I\boldsymbol\Omega = \boldsymbol\tau_{\text{тела}} .
$$

Член $\boldsymbol\Omega\times\mathbf I\boldsymbol\Omega$ называется гироскопическим, он переворачивает теннисную ракетку (эффект Джанибекова). Нётер: сдвиг во времени даёт энергию $E = \tfrac12 m|\mathbf v|^2 + \tfrac12\boldsymbol\Omega\cdot\mathbf I\boldsymbol\Omega + mgy$. Сдвиг даёт импульс $\mathbf P = m\mathbf v$. Поворот мира даёт **вектор** момента импульса в мире $\mathbf L = R\,\mathbf I\boldsymbol\Omega$. Кроме того, у свободного тела $|\mathbf L|$ и энергия вращения сохраняются и в осях тела, это квадратичные инварианты уравнения Эйлера.

Диссипация. Глобальное затухание решателя (`linearDamping` $c$, `angularDamping` $c_a$) есть функция Рэлея $R = \tfrac12\big(c\,m|\mathbf v|^2 + c_a\,\boldsymbol\omega\cdot\mathbf I\boldsymbol\omega\big)$, и $dE/dt = -2R$.

### Дискретизация

- **Поступательное движение.** Схема «сначала скорость, потом положение» ($\mathbf v \mathrel{+}= h\mathbf g$, затем $\mathbf x \mathrel{+}= h\mathbf v$) есть симплектический Эйлер. Она вариационная: это дискретное уравнение Эйлера–Лагранжа для $L_d$ с потенциалом в конце шага. Импульс свободного тела она сохраняет точно.
- **Уравнение Эйлера.** Решается **неявной средней точкой**: $\mathbf I(\boldsymbol\Omega_1 - \boldsymbol\Omega_0) + h\,\boldsymbol\Omega_m\times\mathbf I\boldsymbol\Omega_m = 0$, $\boldsymbol\Omega_m = \tfrac12(\boldsymbol\Omega_0 + \boldsymbol\Omega_1)$, тремя шагами Ньютона. Средняя точка симплектична и сохраняет **оба** квадратичных инварианта в осях тела.
- **Поворот.** Свободный поворот — симметричное расщепление на точные повороты вокруг главных осей, $R_1(h/2)\,R_2(h/2)\,R_3(h)\,R_2(h/2)\,R_1(h/2)$ (McLachlan 1993; Dullweber, Leimkuhler, McLachlan 1997): каждый подшаг — точный поток одной части гамильтониана, композиция симплектична и второго порядка, вектор $\mathbf L$ в мире сохраняется до округления. До 2026-09-28 ориентация продвигалась экспонентой от угловой скорости **конца** шага, и $\mathbf L$ дрейфовал с первым порядком по шагу ($2.8\cdot10^{-3}$ за 20 с); теперь $6.9\cdot10^{-6}$, а ошибка энергии падает как $dt^2$ (глава 2, «Свободный поворот»).

## 11.3 Сочленения и контакты

### Действие

Суставы и контакты не добавляют энергии, они только ограничивают движение. Сустав есть голономная связь $C(q) = 0$. Для шарового сустава это совпадение точки тела с точкой опоры: $C = \mathbf x + R\,\mathbf r - \mathbf p = 0$.

$$
S = \int \Big(\sum_{\text{тела}} L_i - \sum_{\text{связи}} \boldsymbol\lambda_j\cdot C_j(q)\Big)\,dt .
$$

Контакт есть односторонняя связь $C \ge 0$ (зазор). Трение кулоново, с функцией Рэлея $R = \mu N|\mathbf v_t|$.

### Уравнения

$M\dot{\mathbf v} = \mathbf f - J^{\mathsf T}\boldsymbol\lambda$ вместе с $C(q) = 0$ для суставов. За шаг удобнее импульс $\boldsymbol\Lambda = h\boldsymbol\lambda$, и связь ставится на скорости: $J\mathbf v = 0$. Для контакта действуют условия дополнительности $\Lambda_n \ge 0$, $v_n \ge 0$, $\Lambda_n v_n = 0$. Трение выбирается по **принципу максимальной диссипации** (Moreau 1988; Stewart & Trinkle 1996): из всех сил в конусе $|\mathbf F_t| \le \mu N$ природа берёт ту, что рассеивает больше всего энергии, то есть противоположную скольжению. Это вариационный принцип для трения: минимум мощности $\mathbf F_t\cdot\mathbf v_t$ по конусу.

Работа реакции сустава равна нулю. Работа трения за время скольжения равна $\mu N\,s$, где $s$ есть путь. Поэтому для скользящего бруска $\Delta E = -\mu m g\,s$ и путь до остановки $s = v_0^2/(2\mu g)$.

### Дискретизация

Импульсы контактов за шаг есть решение задачи дополнительности (LCP). Она сама вариационная: это условия Каруша–Куна–Таккера для минимума $\tfrac12\boldsymbol\Lambda^{\mathsf T}A\boldsymbol\Lambda - \mathbf b^{\mathsf T}\boldsymbol\Lambda$ при $\boldsymbol\Lambda \ge 0$, где $A = JM^{-1}J^{\mathsf T}$. Последовательные импульсы (Catto 2005) есть проективный Гаусс–Зейдель для этого минимума. Блочный решатель находит его точно для четырёх точек одного многообразия.

Где схема отходит от действия:

- **Коррекция проникновения** (Baumgarte, $\beta = 0.2$) добавляет к связи скорость $\beta C/h$. Эта скорость не из действия. Разделённый импульс уносит её в псевдоскорости, чтобы она не попала в импульс тел.
- **Отскок** $v_n^+ = -e\,v_n^-$ есть закон Ньютона для удара, феноменология, не следствие действия.
- **Сопротивление качению** есть ещё одна феноменологическая функция Рэлея.

## 11.4 Ткань и мягкие тела

### Действие

Частицы с массами $m_i$ и потенциальная энергия связей. Каждая нить ткани есть упругая связь $C_j(\mathbf x) = |\mathbf x_a - \mathbf x_b| - \ell_j$ с жёсткостью $k_j$:

$$
S = \int \Big(\sum_i \tfrac12 m_i|\dot{\mathbf x}_i|^2 - \sum_j \tfrac12\,k_j\,C_j(\mathbf x)^2 - \sum_i m_i g\,y_i\Big)\,dt .
$$

Податливость $\alpha_j = 1/k_j$. Нерастяжимая нить есть предел $\alpha \to 0$, и тогда энергия нити становится связью с множителем. У мягкого тела энергия формы по Мюллеру: $E = \tfrac k2\sum_i m_i\,|R(\mathbf x_i^0 - \mathbf c^0) + \mathbf c - \mathbf x_i|^2$, где $R$ есть лучший поворот (Müller et al. 2005).

### Уравнения

$m_i\ddot{\mathbf x}_i = -\sum_j k_j C_j\,\nabla_i C_j + m_i\mathbf g$. Если ввести $\lambda_j = -k_j C_j$ как отдельную переменную, получается смешанная форма $C_j + \alpha_j\lambda_j = 0$, и сила нити равна $\lambda_j\nabla C_j$. Нётер: без тяжести сохраняются импульс и момент импульса, потому что энергия нити зависит только от расстояния.

### Дискретизация

**Неявный Эйлер как минимум** (Gast et al. 2015; Bouaziz et al. 2014). Шаг неявного Эйлера точно равен минимизации

$$
\mathbf x_{n+1} = \arg\min_{\mathbf x}\ \tfrac12\,\|\mathbf x - \tilde{\mathbf x}\|^2_M + h^2\,U(\mathbf x),\qquad \tilde{\mathbf x} = \mathbf x_n + h\mathbf v_n + h^2 M^{-1}\mathbf f_{\text{внеш}} .
$$

Это **дискретное действие** шага: инерция плюс потенциал. **XPBD** (Macklin, Müller, Chentanez 2016) решает условия минимума в смешанной форме: для каждой связи

$$
\Delta\lambda_j = \frac{-C_j - \tilde\alpha_j\lambda_j}{\nabla C_j^{\mathsf T} M^{-1}\nabla C_j + \tilde\alpha_j},\qquad \tilde\alpha_j = \frac{\alpha_j}{h^2},
$$

и натяжение нити равно $T = \lambda/h^2$. Нити решаются целиком прогонкой, по Сервину–Лакуршьеру.

Где схема отходит от действия: неявный Эйлер **не симплектичен**. Он отнимает энергию у колебаний, сильнее у быстрых. Поэтому ткань в XPBD затухает сама, без трения. Малые шаги (Macklin et al. 2019) уменьшают эту потерю, но не убирают её.

### Код

- Одна связь XPBD: [Cloth.cpp:200](../src/particles/Cloth.cpp#L200), `solveConstraint`.
- Мягкое тело, притяжение к лучшей форме: [SoftBody.cpp:152](../src/particles/SoftBody.cpp#L152), `solveShapeMatching`.

Отдельного графика баланса ткани пока нет. Статическое натяжение и разрыв проверяют тесты `cloth: threads carry the static load and tear at their strength` и `cloth: a sheet swinging on its pinned edge loses no thread` (глава [3](03-particles.md)). Следующий график: энергия качающегося полотна и её потеря на неявном Эйлере при трёх шагах.

### Границы

- Численное затухание неявного Эйлера не измерено этой главой. Это ближайший тест, который надо добавить.

## 11.5 Жидкость частицами (PBF)

### Действие

Лагранжиан SPH (Eckart 1960; Price 2012): частицы несут массу $m_i$, плотность считается ядром, внутренняя энергия зависит от плотности.

$$
S = \int \sum_i m_i\Big(\tfrac12|\dot{\mathbf x}_i|^2 - u(\rho_i) - g\,y_i\Big)\,dt,\qquad \rho_i = \sum_j m_j\,W(\mathbf x_i - \mathbf x_j, h).
$$

Для несжимаемой жидкости внутренняя энергия заменяется связью «плотность равна покоящейся» с множителем для каждой частицы: $C_i = \rho_i/\rho_0 - 1 = 0$.

### Уравнения

Вариация даёт $m_i\ddot{\mathbf x}_i = -\sum_j m_im_j\big(\tfrac{P_i}{\rho_i^2} + \tfrac{P_j}{\rho_j^2}\big)\nabla W_{ij} + m_i\mathbf g$. Сила симметрична по паре $i, j$ и направлена вдоль $\mathbf x_i - \mathbf x_j$. Поэтому из действия **сразу** следует точное сохранение импульса и момента импульса: действие не меняется ни при сдвиге, ни при повороте всех частиц. В несжимаемом пределе давление есть множитель связи плотности.

### Дискретизация

PBF (Macklin & Müller 2013) решает связи плотности как XPBD с нулевой податливостью: множитель $\lambda_i$ на частицу, поправка положения $\Delta\mathbf p_i = \frac1{\rho_0}\sum_j(\lambda_i + \lambda_j + s_{\text{corr}})\nabla W_{ij}$. Пара получает равные и противоположные поправки, поэтому импульс сохраняется по построению.

Где схема отходит от действия:

- **Искусственное давление** $s_{\text{corr}}$ не из действия. Оно борется со слипанием частиц.
- **Вязкость XSPH** есть сглаживание скорости, а не функция Рэлея. Её потеря энергии не посчитана.
- **Удержание вихрей** (vorticity confinement) **добавляет** энергию по замыслу: оно возвращает то, что сгладил перенос.

### Код

- Множители плотности: [DensitySolver.cpp:81](../src/particles/DensitySolver.cpp#L81), `computeLambda`.
- Симметричная поправка положения: [DensitySolver.cpp:125](../src/particles/DensitySolver.cpp#L125), `computeDeltaP`.
- XSPH и удержание вихрей: [DensitySolver.cpp:166](../src/particles/DensitySolver.cpp#L166), `applyViscosityAndVorticity`.

### Графики

Графика баланса пока нет. Ошибка плотности покоящейся воды проверяется тестом `particles rest`, фронт обрушения плотины тестом `benchmark: dam break front vs Martin & Moyce 1952` (глава [9](09-benchmarks.md)). Следующий график: энергия плещущейся воды в закрытом ящике и её потеря на XSPH.

## 11.6 Газ

### Действие

Несжимаемая идеальная жидкость по Арнольду (Arnold 1966): движение есть отображение $X(\mathbf a, t)$ частиц из начального положения $\mathbf a$. Действие есть кинетическая энергия со связью «объём не меняется», и давление есть её множитель Лагранжа:

$$
S = \int\!\!\int \Big(\tfrac12\rho\,|\partial_t X|^2 - p\,\big(\det\nabla_{\mathbf a}X - 1\big) - \rho'\,g\,y\Big)\,d^3a\,dt .
$$

$\rho'$ есть отклонение плотности от фоновой: горячий газ легче, отсюда плавучесть. Арнольд показал, что без плавучести это геодезические на группе сохраняющих объём отображений. Симметрия «перемаркировки частиц» даёт теорему Кельвина о циркуляции.

### Уравнения

$$
\rho\big(\partial_t\mathbf u + \mathbf u\cdot\nabla\mathbf u\big) = -\nabla p + \rho'\mathbf g + \nabla\cdot(2\nu\rho\,\mathbf S),\qquad \nabla\cdot\mathbf u = 0 .
$$

Вязкость пришла из функции Рэлея $R = \nu\rho\int|\mathbf S|^2\,dV$, где $\mathbf S = \tfrac12(\nabla\mathbf u + \nabla\mathbf u^{\mathsf T})$ есть тензор скоростей деформации. Для несжимаемого течения её вклад равен $\nu\rho\nabla^2\mathbf u$, и кинетическая энергия убывает со скоростью $2R$:

$$
\frac{dK}{dt} = -2\nu\rho\int|\mathbf S|^2\,dV .
$$

У вихря Тейлора–Грина $u = \sin\pi x\cos\pi y$, $v = -\cos\pi x\sin\pi y$ это даёт $K(t) = K_0\,e^{-4\nu\pi^2 t}$ (Taylor & Green 1937).

### Дискретизация

**Проекция давления есть множитель.** Шаг проекции ищет ближайшее бездивергентное поле:

$$
\mathbf u^{n+1} = \arg\min_{\nabla\cdot\mathbf u = 0}\ \tfrac12\rho\,\|\mathbf u - \mathbf u^*\|^2
\quad\Longrightarrow\quad
\mathbf u^{n+1} = \mathbf u^* - \frac{h}{\rho}\nabla p,\qquad \nabla^2 p = \frac{\rho}{h}\nabla\cdot\mathbf u^* .
$$

Давление $p$ здесь в точности множитель Лагранжа связи $\nabla\cdot\mathbf u = 0$, как в действии Арнольда. Проекция ортогональна, поэтому кинетическую энергию она только уменьшает, никогда не добавляет.

Где схема отходит от действия:

- **Перенос** полулагранжев с поправкой MacCormack. Он не вариационный и рассеивает энергию сам, без вязкости. Вариационная схема для этой задачи существует (Pavlov et al. 2011), её цена: неявная нелинейная система на каждом шаге.
- **Вязкость** считается неявным Эйлером, 20 итерациями Якоби. Она устойчива при любом шаге, но тоже отходит от $e^{-4\nu\pi^2t}$ на величину порядка $\nu h\pi^2$.

## 11.7 Тепло и горение

### Действие

**Действия нет.** Теплопроводность, горение и излучение необратимы: энтропия только растёт. Вместо принципа стационарного действия здесь работает другая пара принципов:

- **Вариационный принцип Онзагера** (Onsager 1931): поток тепла минимизирует «рэлеевиан» $\dot F + \Phi$, скорость роста свободной энергии плюс диссипацию.
- **GENERIC** (Grmela & Öttinger 1997): обратимая часть движения идёт от энергии, необратимая от энтропии.

### Уравнения

$\rho c_p\,\partial_t T = \nabla\cdot(\kappa\nabla T) + q$, закон Фурье. Производство энтропии $\sigma = \kappa|\nabla T|^2/T^2 \ge 0$. Это и есть «второй закон» в локальной форме. Горение по Аррениусу есть химическая кинетика со скоростью $\propto e^{-E_a/RT}$, тоже необратимая.

### Дискретизация

Неявная схема для теплопроводности сохраняет полную энергию (сумму $\rho c_pT$) при закрытых стенках и не создаёт отрицательных температур. Шаг горения решает баланс энергии реакции неявно (глава [5](05-fire.md)).

- Горение: [Combustion.cpp:13](../src/gas/Combustion.cpp#L13), `Combustion::react`.

## 11.8 Магнитная гидродинамика

### Действие

Идеальная МГД по Ньюкомбу (Newcomb 1962). Поле **вморожено** в плазму: при отображении частиц $X(\mathbf a, t)$ с якобианом $\mathcal J = \det\nabla_{\mathbf a}X$ плотность и поле переносятся как $\rho = \rho_0/\mathcal J$ и $\mathbf B = (\nabla_{\mathbf a}X)\,\mathbf B_0/\mathcal J$.

$$
S = \int\!\!\int \Big(\tfrac12\rho_0|\partial_t X|^2 - \rho_0\,e(\rho) - \frac{|\mathbf B|^2}{2\mu_0}\,\mathcal J\Big)\,d^3a\,dt .
$$

Магнитная энергия $|\mathbf B|^2/2\mu_0$ играет роль потенциальной. Симметрии: сдвиг во времени даёт энергию. Перемаркировка частиц даёт вмороженность и сохранение магнитной спиральности $\int\mathbf A\cdot\mathbf B\,dV$.

### Уравнения

Вариация по $X$ даёт уравнение движения с силой Лоренца:

$$
\rho\frac{D\mathbf u}{Dt} = -\nabla p + \mathbf J\times\mathbf B,\qquad \mathbf J = \frac{\nabla\times\mathbf B}{\mu_0},\qquad \partial_t\mathbf B = \nabla\times(\mathbf u\times\mathbf B) .
$$

Сопротивление добавляется функцией Рэлея закона Ома, $R = \tfrac12\int\mathbf J^2/\sigma\,dV$. Тогда $\mathbf E = -\mathbf u\times\mathbf B + \eta\mu_0\mathbf J$ с $\eta = 1/(\mu_0\sigma)$, и в покоящемся проводнике между идеально проводящими стенками

$$
\frac{d}{dt}\int\frac{|\mathbf B|^2}{2\mu_0}dV = -\int\frac{\mathbf J^2}{\sigma}\,dV .
$$

Вся магнитная энергия уходит в джоулево тепло.

### Дискретизация

**Constrained transport** (Evans & Hawley 1988) есть дискретное внешнее исчисление: $\mathbf B$ живёт на гранях ячеек как поток (2-форма), $\mathbf E$ и $\mathbf J$ живут на рёбрах как циркуляция (1-форма). Дискретный ротор с рёбер на грани и дискретный ротор с граней на рёбра сопряжены друг другу. Поэтому суммирование по частям выполняется **точно**, и дискретный баланс энергии $dW/dt = -\sum_{\text{рёбра}}\mathbf E\cdot\mathbf J\,dV$ верен до округления. На рёбрах идеально проводящей стенки $\mathbf E = 0$, работы там нет. $\nabla\cdot\mathbf B = 0$ держится до округления по той же причине. Вариационная дискретизация МГД целиком описана у Gawlik et al. (2011).

Где схема отходит от действия: противопоточная добавка к $\mathbf E$ (`numericalDissipation`) есть численная функция Рэлея. Её рассеяние не входит в тепло газа. Шаг по времени явный, поэтому баланс выполняется с ошибкой порядка $\eta k^2 h$.

## 11.9 Магниты

### Действие

Два точечных диполя $\mathbf m_1$, $\mathbf m_2$ на твёрдых телах. Энергия диполя в поле другого $U = -\mathbf m_2\cdot\mathbf B_1(\mathbf r)$, где $\mathbf r$ есть вектор между ними, и

$$
S = \int\Big(T_1 + T_2 + \mathbf m_2\cdot\mathbf B_1(\mathbf r)\Big)\,dt,\qquad
\mathbf B_1(\mathbf r) = \frac{\mu_0}{4\pi}\,\frac{3\hat{\mathbf r}(\hat{\mathbf r}\cdot\mathbf m_1) - \mathbf m_1}{r^3}.
$$

$U$ зависит только от разности положений и от взаимного поворота. Поэтому сдвиг и общий поворот пары её не меняют.

### Уравнения

Сила $\mathbf F = \nabla(\mathbf m_2\cdot\mathbf B_1)$ и момент $\boldsymbol\tau = \mathbf m_2\times\mathbf B_1$ (Jackson, 5.56). Нётер: сила на второй магнит равна минус силе на первый, и суммарный импульс пары сохраняется.

### Дискретизация

Сила и момент прикладываются импульсом один раз за кадр, после шага решателя. Это явная схема, не вариационная. Сохранение импульса пары остаётся точным, потому что импульсы равны и противоположны в один момент.

## 11.10 Относительность

### Действие

Свободная частица в искривлённом пространстве-времени идёт по пути наибольшего собственного времени:

$$
S = -mc\int d\tau = -mc\int\sqrt{-g_{\mu\nu}\,\dot x^\mu\dot x^\nu}\;d\lambda .
$$

С аффинным параметром удобнее равносильное действие $S = \int\tfrac12 g_{\mu\nu}\dot x^\mu\dot x^\nu\,d\lambda$, годное и для света. Для контекста: само пространство-время подчиняется действию Эйнштейна–Гильберта $S = \frac{c^4}{16\pi G}\int R\sqrt{-g}\,d^4x$. SDK его не решает, метрика Керра задана. Но по любой метрике SDK считает кривизну и тензор Эйнштейна $G_{\mu\nu}$, то есть проверяет, решает ли она уравнения этого действия ([гл. 8.5](08-relativity.md#85-кривизна-из-метрики)).

### Уравнения

Преобразование Лежандра даёт гамильтониан $H = \tfrac12 g^{\mu\nu}p_\mu p_\nu$ и уравнения

$$
\frac{dx^\mu}{d\lambda} = g^{\mu\nu}p_\nu,\qquad \frac{dp_\mu}{d\lambda} = -\frac12\,\frac{\partial g^{\alpha\beta}}{\partial x^\mu}\,p_\alpha p_\beta .
$$

Нётер: метрика Керра не зависит от $t$ и $\varphi$, отсюда $E = -p_t$ и $L_z = p_\varphi$. Скрытая симметрия, тензор Киллинга, даёт постоянную Картера $Q$ (Carter 1968).

### Дискретизация

Интеграторы RK4 и Дорманд–Принс RK5(4) не симплектичны. $E$ и $L_z$ всё равно сохраняются точно, до округления: производные метрики по $t$ и $\varphi$ равны нулю, поэтому $p_t$ и $p_\varphi$ не меняются ни на одной стадии. $Q$ дрейфует. Симплектический интегратор с ограниченной ошибкой в плане (глава [8](08-relativity.md)).

### Код

- Правая часть уравнений Гамильтона: [Geodesic.cpp:41](../src/relativity/Geodesic.cpp#L41), `Geodesic::derivative`.
- Шаг с контролем точности: [Geodesic.cpp:93](../src/relativity/Geodesic.cpp#L93), `Geodesic::stepRK45`.

### Графики

Графика в этой главе пока нет. Дрейф $Q$ печатает тест `geodesics: E, L and Carter's Q along a Kerr orbit (RK45 vs RK4)`. Следующий график: дрейф $Q$ за $10^6$ витков, RK4 против симплектической схемы.

### Границы

| Интегратор | Дрейф $Q$ | Где измерено |
|---|---|---|
| RK45, допуск $10^{-12}$ | $6\cdot10^{-10}$ за 20 000 $M$ | глава [8](08-relativity.md) |
| RK4, шаг $2M$ | $8\cdot10^{-6}$, растёт со временем | глава [8](08-relativity.md) |

Квантовых поправок нет, метрика не отвечает на вещество.

## 11.11 Как пересобрать графики

Тесты пишут CSV, только если задана папка. Обычный прогон тестов ничего не пишет.

```bash
RF_PLOT_DIR=plots RF_TEST="action:" ./rf_tests          # пять тестов пишут plots/*.csv
python tools/plot_action.py plots docs/images/action   # SVG для этой главы
```

Скрипт использует только стандартную библиотеку Python. Каждый SVG несёт свою светлую и тёмную палитру, подписи осей с единицами, легенду и подпись с именем теста.
